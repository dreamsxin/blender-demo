# 公主城堡 (princess castle)

程序化生成的童话风城堡：奶油色石墙、粉紫锥顶、金色尖顶与旗帜，中央主塔配玫瑰窗与阳台，
四座高矮不一的角塔，带垛口的城墙，拱券门楼与台阶，下面是分层岩石台基。日光侧前打光。

全部几何体由脚本生成（274 个物体），没有外部模型和贴图。

## 跑

```powershell
& "D:\Program Files\Blender Foundation\Blender 5.2\blender.exe" -b --factory-startup `
  --python "D:\work\blender\demos\architecture\princess-castle\scripts\build_castle.py" -- `
  --engine cycles --samples 96 --res 1440
```

- `--engine cycles|eevee`：eevee 出图快（十几秒）适合看构图，成品图用 cycles
- `--samples` / `--res` / `--out`：采样数、横向分辨率（输出 4:3）、输出路径
- 跑完把场景存成 `princess_castle.blend`

## 结构 / 参数

脚本顶部常量（Blender 单位 ≈ 米）：

- `KEEP_R / KEEP_H` — 主塔半径与墙体高度（锥顶另算 `roof_ratio × 半径`）
- `TOWER_SPEC` — 四座角塔的 `(x, y, 半径, 墙高)`，高矮错落是城堡好看的关键
- `WALL_H / WALL_T` — 城墙高度与厚度；垛口按墙长自动排布
- `BASE_R` — 台基半径；岩石分三层向下收
- `GATE_W` — 门洞宽度，门楼拱券与台阶都按它算

## 实现要点

- **塔 `tower()`**：台座 + 塔身 + 两道石箍 + 檐口 + 锥顶 + 金尖顶 + 旗杆旗面，
  外加两圈拱窗；一个函数复用在主塔、角塔、门楼小塔上，只换半径高度。
- **拱窗 `window()`**：石框 + 暖光玻璃 + 半圆拱顶，按圆柱面的极角摆放并旋转朝外，
  玻璃自发光让傍晚的窗户"亮着"。
- **城墙 `wall()`**：给两个端点，自动算长度与朝向，生成墙体 + 走道 + 按 0.66 m 间隔的垛口。
- **门楼 `gatehouse()`**：整块正面墙上贴 11 块小石头拼出半圆拱券，木门 + 横铁条 + 四级台阶。
- **玫瑰窗**：环形石框 + 自发光玻璃盘 + 六道放射石棂。
- **布光**：太阳从相机侧前方左上打来（`rotation_euler = (45°, 0, -45°)`），
  天空用 Nishita，但通过 `Light Path → Is Camera Ray` 把"给相机看的天空"和
  "参与照明的天空"分开：背景全亮度、照明只留 0.04，太阳才能主导明暗和投影。

## 踩过的坑

- 天空贴图直接当主光源会把整个画面照成没有明暗的奶白色，必须压低照明分量。
- 太阳方位一开始设在城堡背后，正面全是天光 → 完全没有立体感；改到相机侧前方才有明暗分界和投影。
- 门楼最初用"两墩子 + 门楣"拼，墩子与门楣之间留出的缝在渲染里是两块黑洞，改成整块正面墙解决。

## 已知可调项

- 没做护城河、吊桥、旗帜飘动、屋顶瓦片纹理
- 窗户位置是固定角度，密集塔身上会显得规律
- 岩石台基是圆柱堆叠，需要更自然的话可以叠 Displace 修改器
