# 清明上河图 低多边形长卷动画

按原作的三段式结构程序化生成的宋代汴京长卷：**郊野 → 汴河虹桥 → 城内街市**，
镜头像展开长卷一样沿河匀速横移 70 个单位。低多边形彩色风格，EEVEE 出片。

不是原作的临摹，而是取其结构与母题（虹桥、漕船、纤夫、驴队、城门楼、彩楼欢门、街市摊铺）
做的三维演绎；全部几何体由脚本生成（约 1150 个物体、90 多个人物），没有外部模型和贴图。

## 三段内容

| 段 | x 范围 | 内容 |
| --- | --- | --- |
| 郊野 | −46 … −24 | 疏林垂柳、田垄、三处茅舍、两支驴队驮货进城、田间行人 |
| 汴河虹桥 | −24 … 2 | 虹桥居中，六条漕船（带桅帆/船篷/船工）、码头、纤夫拉纤、两岸屋舍酒楼与摊铺 |
| 城内街市 | 2 … 28 | 城门楼（城墙 + 券门 + 重檐楼 + 匾额）、密集二层店铺、彩楼欢门酒楼、轿子、牛车、骆驼队、稠密人流 |

## 结构 / 参数

脚本顶部常量：

- `SEC_RURAL / SEC_RIVER / SEC_CITY` — 三段的 x 范围，改这里就能调整各段长度比例
- `BRIDGE_X / GATE_X` — 虹桥与城门楼的位置
- `SCROLL_FROM / SCROLL_TO` — 镜头横移的起止 x（决定"卷"展开多长）
- `RIVER_HALF / BANK_H` — 河道半宽、岸高
- `--seconds` 控制时长；船的漂移速度按秒数等比缩放，快慢观感一致

## 实现要点

- **虹桥**：把桥面拆成 14 段，每段沿 `z = BANK_H + rise·sin(πt)` 的正弦拱线摆放并按切线角旋转，
  栏杆与桥下叠梁同一套参数复用，桥上顺带撒了 7 个行人。
- **屋舍**：`house()` 白墙 + 木柱 + `wedge()` 做的三角棱柱悬山顶，随机瓦顶/茅顶、
  可选二层（阳台 + 栏杆 + 二重檐）、可选临街幌子和自发光灯笼。
- **货船**：平底船身 + 两端用 `wedge` 旋转 90° 拼出的翘头翘尾 + 三段拱形船篷 + 桅帆，
  船工位置随船一起算进人群列表。
- **人群**：`person()` 生成单个小人（圆柱身 + 二十面体头 + 三分之一戴斗笠）；
  街上的人先收集坐标再批量生成，**船工则直接建出来并入船的构件列表**，
  这样船漂走时船工跟着一起走，不会留在水面上。
- **驴队 / 骆驼 / 牛车 / 轿子**：`quadruped()` 一个身子四条腿 + 驮货，骆驼多一个驼峰；
  轿子是轿厢 + 两根贯穿的轿杠 + 前后两个轿夫；牛车是车板 + 两个轮子 + 辕 + 一头牛。
- **城门楼**：城墙分两段留出门洞，11 块小石头拼券门，城台上叠两重檐楼加匾额，
  墙顶按长度自动排垛口。
- **展卷镜头**：相机朝向固定不变，只给 x 打两个关键帧（起点/终点），
  所以画面是纯粹的横向平移，和看长卷的体验一致。
- **匀速**：Blender 5.x 的 `Action` 已经没有 `fcurves` 属性可以后处理插值，
  改成渲染前设 `preferences.edit.keyframe_new_interpolation_type = "LINEAR"`，
  新插的关键帧直接就是线性的。

## 已知可调项

- 人和船目前是刚体位移，没有走路/摇桨动作；要动起来得给腿部做骨骼或用 shape key
- 水面是平板，没有波纹和倒影；可以加 Wave 修改器或法线贴图
- 屋舍屋顶是三角棱柱，不是真正的歇山/庑殿举折
- 想更像原作可以把镜头压低、加雾、把色板换成绢本淡彩（改 `palette()` 一处即可）
